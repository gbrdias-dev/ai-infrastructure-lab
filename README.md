# Sobre o projeto

O **AI Infrastructure Lab** é um laboratório desenvolvido com o objetivo de estudar e implementar uma infraestrutura completa para execução local de modelos de Inteligência Artificial.

O ambiente utiliza diferentes tecnologias para execução de modelos, gerenciamento centralizado, balanceamento de carga e monitoramento da infraestrutura.

A arquitetura foi projetada com foco em **escalabilidade**, permitindo a expansão dos recursos computacionais através da adição de novos servidores de IA.

O projeto também busca reproduzir, em ambiente de laboratório, conceitos utilizados em ambientes de infraestrutura e aplicações de IA em produção.

---

# Objetivos

- 🤖 Hospedar e executar modelos de IA localmente
- 🧠 Estudar diferentes engines de inferência
- ⚖️ Distribuir requisições entre servidores de IA
- 🌐 Centralizar o acesso aos modelos através de uma interface Web
- 👥 Implementar gerenciamento de usuários
- 📊 Monitorar servidores e serviços
- 🔎 Integrar pesquisa Web aos modelos
- 🐳 Utilizar containers para disponibilização de serviços
- 🖥️ Trabalhar com virtualização de infraestrutura
- 📈 Criar uma arquitetura escalável para LLMs
